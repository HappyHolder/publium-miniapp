# Moderator: переход на GPT‑6.1 Sol — 25.10.2026

Статус: подготовлен к production-переключению по запросу владельца.

Целевая модель — `gpt-6.1-sol`, API — Responses со Structured Outputs, `reasoning.effort=medium`. Выбор модели задаётся отдельной переменной `OPENAI_MODERATOR_MODEL`; пустое значение наследует `OPENAI_CHAT_MODEL`. Общая модель ассистента, Community Manager и остальных AI-функций остаётся `gpt-5.6-terra`.

На модель модератора направляются проверка мата, проверка исправления, анализ поведения и отдельное подтверждение повторного нарушения. Журнал записывает именно выбранную модель. Политики, пороги, белый список и пауза не меняются.

Уточнена оценка расхода: используются фактические input/output/cached токены ответа; output включает reasoning. Для стандартного короткого контекста Sol учтены $2 / $10 / $0,10 за миллион входных / выходных / кэшированных входных токенов; для Terra — $2 / $12 / $0,20. Это оценка для технического учёта, а не списание с пользователя или точная замена счёта провайдера.

Проверено до сборки образа:

- Серверная сборка и 217 тестов (88 библиотечных, 48 модератора, 81 Community Manager).
- Тест фактического тела Responses-запросов: обе structured-ветки модератора используют Sol, обычный AI-вызов остаётся на Terra.
- Production-ключ успешно выполнил небольшой синтетический запрос к Sol: Structured Outputs, medium, store=false. Данных чата и сообщений Telegram в проверке нет. Один предварительный запрос завершился сетевым сбоем; успешная проверка заняла около 10,7 секунды.

Подготовлен явный платный smoke `node scripts/moderator-model-smoke.mjs --live`: восемь искусственных примеров мата, цитирования, несогласия, личного выпада, критики бота и угрозы. Без `--live` сценарий отказывается работать; сеть ограничена OpenAI Responses, обращений к БД и Telegram нет. Изолированная SQL/HTTP-проверка модератора дополнительно проверяет выбранную модель на всех стадиях.

Совместимость и тарифы сверены с [официальной страницей Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol) и [рекомендациями по миграции](https://developers.openai.com/api/docs/guides/deployment-checklist). Настройки reasoning и существующие инструкции сохранены; изменение одних только моделей не доказывает улучшение точности на живом чате.

После переключения здесь фиксируются результаты прогона образа, реальные названия моделей, health и сохранение паузы.
