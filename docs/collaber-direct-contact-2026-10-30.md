# Collaber: прямой контакт, 30 октября 2026

## Состав релиза

Актуальный сценарий: запрос → подходящие участники → исходное интро → «Написать». Пользователь отказался от знакомств через бота. Этот документ заменяет соответствующие пункты прежнего плана финализации.

- Кнопка «Познакомить», её переключатель, предпросмотр и счётчик знакомств удалены. Старое `buttons.introduce` игнорируется при чтении настроек.
- Обработчики создания приглашения, принятия и передачи контактов удалены. Старые кнопки отвечают только уведомлением об отключении функции. Уже поставленные задачи `INVITE_DELIVERY` и старые callback-задачи отменяются без отправок, в том числе при паузе CM.
- Исторические приглашения больше не исключают людей из поиска и обновления выдачи на 30 дней. Таблица сохранена для совместимости; `/forget` продолжает очищать старые данные участника. Миграций и удаления исторических таблиц нет.
- Согласие на публичные рекомендации (`publicMentions`, кнопки `cp:…`) сохранено. Оно управляет видимостью профиля и не является согласием на знакомство.
- Уточнение сохраняет исходный запрос в группе и личке. Ссылка перехода подписана, привязана к запросу и проверяет автора; `/search` начинает новый поиск.
- `/hide`, `/forget`, `/show` и команды с адресом бота обрабатываются в группе; команды другому боту игнорируются. Скрытие и удаление доступны при паузе. Подтверждение направляется в исходный чат.
- После исключения ушедшего кандидата проверяются резервные решения модели, до десяти проверок. Выдача ограничена двумя людьми в группе и тремя в личке. Возвращение участника подтверждается доступом или новым групповым сообщением.
- Панель отменяет устаревшие поисковые запросы, игнорирует запоздавшие ответы, блокирует пересекающиеся мутации и сбрасывает состояние при смене сообщества. Загрузка обложки сохраняет актуальные настройки.
- Счётчики доступных профилей исключают ушедших участников. Ссылки на подтверждённые интро из hotfix `c1aa0cb` сохранены.

Не входят: очередь приглашений, подтверждения доставки контактов, панель знакомств и миграция `20261015120000_collaber_delivery` из старого локального набора изменений.

## Проверки

- Серверная сборка; полный набор библиотек и Moderator (88 + 52 теста), итоговый набор Community Manager (87 тестов); security smoke.
- Production frontend build и smoke: основные экраны, закрытая авторизация без Telegram initData и Telegram fallback. Для браузерной проверки потребовался доступ к локальному preview вне sandbox.
- Playwright на синтетических данных, 320/390 px: отсутствие элементов знакомств, прямой контакт и интро, порядок поисковых ответов, двойное нажатие мутации, обновление текущего фильтра, смена сообщества; без горизонтального переполнения и ошибок JavaScript. Команда `npm run test:collaber-ui` включена в CI.
- Релизный API-образ прошёл проверку на отдельном PostgreSQL-контейнере с пустой `publium_audit_*` базой: 62 миграции, отсутствие расхождений схемы и полный интеграционный сценарий. Telegram и AI заменены заглушками; рабочие профили и сообщения не использовались.
- В интеграции проверяются отключённые старые кнопки/задачи, отсутствие cooldown старых приглашений, подписанное уточнение, резервные кандидаты, согласия на публичный показ, удаление профиля, ссылки на интро и команды при паузе.

## Изоляция выкладки

На сервере обнаружены отдельные незакоммиченные правки Moderator. Они не входят в этот коммит. Кандидат API собран поверх сохранённого текущего production-образа с заменой только десяти изменённых production-модулей `dist/communityManager/` и интеграционного runner. Зависимости и Prisma schema сверены с рабочими файлами сервера. Остальные исполняемые модули образа, серверные правки и окружение сохраняются.

Образы и журналы: `/opt/publium-releases/collaber-direct-20261030`. Предыдущие API/web сохранены как `before-collaber-direct-20261030`. Перед переключением проверяются исходные идентификаторы работающих образов; база не перезапускается.

## Production

Релиз `6145ccc` выложен 30 октября 2026. Обновлены API и web; база сохранила прежний контейнер. Неприменённых миграций нет.

- В работающем API совпали хеши всех десяти изменённых production-модулей CM с проверенной сборкой.
- Синтетическая карточка в работающем API содержит прямой контакт и подтверждённый URL интро, без callback знакомства. Старое `buttons.introduce: true` не возвращает кнопку.
- Публичные health, index и оба проверенных JavaScript-ресурса вернули HTTP 200. Хеши ресурсов совпали с локальной production-сборкой; entry: `/assets/index-BlDPqc2m.js`.
- До и после fast-forward совпал хеш незакоммиченного diff Moderator. Отдельно совпали совокупные хеши всех файлов `dist/moderator` в предыдущем и новом API-образе. Токены и окружение не менялись.
- У API/web ноль перезапусков после запуска, ошибок Collaber в проверенном журнале нет. Временные PostgreSQL-контейнер и сеть удалены.

Проверочных сообщений в Telegram не отправляли. Реальная переписка участников и переход по кнопке в их Telegram-клиенте автоматическими тестами не подтверждаются. Старые сообщения массово не редактировались; их кнопки знакомства больше не запускают приглашения.
