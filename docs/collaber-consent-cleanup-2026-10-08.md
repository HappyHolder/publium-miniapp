# Удаление служебного запроса видимости Collaber

После выбора «Да, в группе» или «Только лично» сначала сохраняется настройка профиля, затем удаляется исходное служебное сообщение бота. Интро участника и сообщения с подбором не удаляются. Дополнительное подтверждение в чат не отправляется.

ID удаляемого сообщения берётся из журнала отправки конкретного CONSENT_PROMPT, а не из callback или номера интро. Проверка автора согласия сохранена. Ошибка удаления не отменяет выбор; повтор обработки удаляет тот же prompt без повторного предложения знакомства. Ответ Telegram «message to delete not found» считается успешной очисткой. В записи CONSENT остаются источник интро и выбор, добавляется флаг removed.

Telegram ограничивает удаление сообщений возрастом 48 часов: https://core.telegram.org/bots/api#deletemessage. При отказе Telegram выбор сохраняется, ошибка записывается в задачу; новые сообщения взамен не создаются.

Проверки: оба варианта согласия, запрет чужого нажатия, сохранение выбора при ошибке удаления, повтор после ошибки, уже удалённое сообщение, удаление ID prompt вместо ID интро. Всё проверяется в изолированной БД с заглушками Telegram.
