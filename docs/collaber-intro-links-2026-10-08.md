# Collaber: переход к исходному интро

У старого профиля Степана сохранился номер группового интро, но факты были извлечены до сохранения `sourceChatId`. После очистки временной истории `profileIntroLinks` перестал подтверждать источник. Кнопка заменялась callback, публиковавшим копию интро в группу.

Теперь для старых профилей дополнительным подтверждением служит сохраняемая запись группового согласия: тот же менеджер, чат, участник и номер исходного сообщения. Этот способ исключён для профилей с ручным редактированием, чтобы номер сообщения из лички не стал групповой ссылкой. Новые записи согласия явно хранят чат; факты новых интро уже сохраняют источник.

Кнопка «Интро» создаётся только с подтверждённым URL. Без источника кнопка не показывается. Старые callback-кнопки обновляют клавиатуру существующего подбора, не публикуя копию текста. После такого обновления повторное нажатие открывает ссылку. Остальные настройки оформления сохранены.

Проверки: unit-тест URL-кнопок и отсутствия callback для неизвестного источника; интеграционные сценарии старого интро после очистки истории, чужого чата, совпадающих номеров личного и группового сообщений, обновления старой клавиатуры без новой отправки.
