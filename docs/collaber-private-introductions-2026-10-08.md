# Collaber: личный сценарий знакомства

Кнопка «Познакомить» раньше отправляла подсказки и подтверждение в чат исходного подбора. Теперь проверка до постановки задания в очередь показывает ошибки только нажавшему: чужой или устаревший подбор, скрытый участник, отсутствие личных приглашений у получателя. Используется `answerCallbackQuery` с `show_alert`.

Если инициатор ещё не подключил личный диалог, ответ callback открывает бот со штатной подписанной ссылкой сообщества. После «Старт» нужно повторно нажать «Познакомить». Переход и запуск бота сами по себе не отправляют приглашение.

При подключённых личных диалогах приглашение уходит кандидату, подтверждение — инициатору в личку. Ответы о повторной паре и недоступности личных приглашений при обработке очереди также личные. Публикация подсказки в группу исключена, в том числе для старых заданий без сессии инициатора. Согласие второй стороны по-прежнему обязательно.

Документация Telegram: https://core.telegram.org/bots/api#answercallbackquery (личное уведомление/alert и переход по ссылке запуска бота).

Интеграционные проверки используют заглушки Telegram: чужой аккаунт видит alert, неподключённый автор получает ссылку запуска, неподключённый кандидат — alert только инициатору; успешный сценарий отправляет сообщения только двум личным chat ID. Интерфейс панели и сохранённые настройки не меняются.
