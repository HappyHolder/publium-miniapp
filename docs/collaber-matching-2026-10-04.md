# Collaber: контекст интро и ссылки на источники

## Наблюдения в Test Publium Chat

Проверка началась 03.10 и продолжена 04.10.2026. В рабочей базе пять профилей; все доступны для поиска и разрешены для публичного показа. Четыре новых тестовых интро сохранены от разных Telegram ID. Нажатия согласия обработаны. Пять инициативных запросов имеют `NO_MATCH`; старая личная выдача имеет `SENT` с пустым результатом. Ожидающих задач на момент проверки нет.

Доказанный дефект: исходное интро TON Page содержит описание идентификации и верификации пользователей, но извлечённые факты сохранили только название проекта, навык 3D и общие предложения сотрудничества. До исправления и предварительный поиск, и смысловая оценка кандидатов читали исключительно факты. Описание возможностей проекта было потеряно для подбора, хотя оставалось в `sourceText`.

Разговорный ответ CM с упоминанием Степана использует отдельную память переписки. Он не подтверждает успешную выдачу Collaber. Прежний журнал фиксирует успешный JSON от модели, но не содержит результатов каждого фильтра; нельзя утверждать, что все пять пустых выдач имеют одну и ту же причину.

Текущие настройки: автоматические предложения включены, периодический поиск выключен, максимум одна инициатива за скользящие 24 часа, тихие часы 00–08 по Москве. После неудачной инициативы есть также 24-часовое ограничение повторного инициативного поиска для того же участника. Настройки этим выпуском не меняются. Ручной запрос к боту позволяет проверить подбор без ожидания следующего интро.

## Изменения

- Поиск использует извлечённые факты и релевантные дословные фрагменты исходного интро, до 2400 символов на профиль. Фрагменты не становятся новыми утверждёнными фактами. Смысловая проверка получает сведения о возможностях проекта, учитывает отрицания и отличает предложенную помощь от общей потребности двух людей.
- Некорректный ответ смысловой проверки кандидатов и невозможность проверить членство больше не считаются отсутствием совпадений. Они возвращают ошибку для штатной обработки очередью. Журнал `collaber_matching` содержит числа допущенных профилей, предварительных кандидатов, прошедших смысловую проверку, непроверенных участников и итоговых рекомендаций; тексты интро туда не записываются.
- Кнопка «Интро» открывает исходное сообщение группы, если его происхождение подтверждено. Для новых интро группа сохраняется в происхождении фактов. Для старых — проверяются сохранённое сообщение или источник дайджеста с совпадением автора, номера и текста. Если доказательства нет, остаётся прежний показ сохранённого интро через callback. Номер личного сообщения `/edit` не подставляется в ссылку на группу.
- Разговорный ответ CM получает ссылку на отмеченное `#intro` / `#интро` сообщение, когда модель явно сослалась на него и оно присутствует среди фактических источников разговора. Одного имени в краткой памяти недостаточно для создания ссылки. Старые сообщения Telegram не редактируются.

Источники всех пяти текущих профилей подтверждены чтением рабочей БД. Архив другого чата не импортируется; приглашения и диагностические сообщения участникам не отправляются.

## Проверки и ограничения

- 74 теста Community Manager, серверная сборка и security smoke прошли.
- Сборка frontend и production smoke прошли: основные экраны, запрет mock-данных без авторизации и Telegram launch fallback.
- Интеграция с отдельной БД `publium_audit_collaber_20260921` прошла: все 60 миграций, схема без расхождений. Добавлены проверки потери описания проекта, ссылки на групповой источник, личного редактирования, ошибок модели и проверки членства. AI и Telegram заменены заглушками, внешний доступ запрещён сценарием.
- Новая смысловая выдача настоящей модели на этих пяти профилях пока не подтверждена. Автоматическая проверка разрешений отклонила диагностический вызов, передающий сохранённые интро в OpenAI. Вместо него использованы чтение журналов и изолированные проверки; запросы `NO_MATCH` не ставились на повторную обработку.
- Изменений схемы БД нет. Прохождение GitHub Actions не заявляется.

## Ссылки на сайты проектов

Автоматического чтения сайтов в Collaber сейчас нет. Общий инструмент web research у CM не является обогащением профилей Collaber. В сохранённом интро TON Page остались подписи «Сайт», «MiniApp», «X», но не URL из Telegram `text_link`.

Отдельное расширение должно сохранять URL из entities, читать ограниченное число публичных страниц проекта, кешировать краткую справку с источником и датой, отличать заявления сайта от слов участника и обновлять справку отдельно от каждого поиска. Для сетевого чтения нужны ограничения адресов, редиректов, размера ответа и времени. Этот выпуск обход сайтов не добавляет.
