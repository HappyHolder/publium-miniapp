# Collaber — реализация и проверка, 21 сентября 2026

## Состояние

Collaber развёрнут на сервере; 27.09.2026 включён только в Test Publium Chat. Инициативы выключены. Остальные сообщества сохраняют выключенную функцию. Существующие конфигурации CM совместимы. 22.09 получен и локально проверен JSON истории Collaborations (120 116 записей); подготовлены части импорта и контрольная выборка. Импорт реального архива в БД, оценка рекомендаций владельцем и пилот 7–14 дней ещё не выполнены. Численные критерии исходного плана (50 интро, 30 запросов, 95%/80%) пока не измерены.

Подробности выпуска и оставшиеся действия зафиксированы в конце документа.

## Что реализовано

- CM → «Функции» → Collaber, вкладки «Участники», «Предложения», «Настройки». Общие компоненты, шрифты и тёмно-оранжевая тема проекта. Настройки сохраняются и применяются через существующую панель CM.
- Тип сообщества и цели подбора; поиск по запросу, сбор новых интро, инициативы «выключены / черновики / автоматически», лимит инициатив и срок актуальности.
- Обложка из файла, её замена и отключение; вступительный текст; четыре группы кнопок; живой пример оформления. Загрузка изображений использует существующий API проекта.
- Импорт JSON Telegram Desktop или нормализованного JSON: предпросмотр, примеры сообщений, запуск, прогресс, отмена и продолжение после ошибки. Максимум 10 МБ / 50 000 сообщений. Проверяется ID чата. Совпадение по имени не используется: идентичность привязана к Telegram user ID.
- Фоновые порции по пять сообщений, извлечение собственных профессиональных фактов с точными цитатами, обновления из разрешённых модератором новых сообщений. Правка исходного сообщения заменяет его прежние факты. Полный архив очищается после завершения, отмены или истечения срока предпросмотра.
- Поиск: раскрытие терминов запроса, предварительный отбор до 30 профилей, AI-проверка соответствия задачи предложениям участников, до трёх кандидатов. Нет подходящих людей — честный пустой результат. Учитывается вся история: старые интро не исключаются по возрасту, а сопровождаются просьбой уточнить актуальность. Явно закрытые запросы удаляются из фактов; просроченные потребности не запускают инициативы.
- Инструмент поиска внутри существующего агента CM при прямом обращении; отдельный приватный сценарий выбранного CM-бота. После поиска движок выдаёт одну карточку с проверенными данными.
- «Написать» открывает текущий Telegram username с черновиком текста; сам бот не отправляет этот текст за человека. «Интро» показывает сохранённый источник. «Познакомить» отправляет приглашение только при начатом личном диалоге обоих участников; подтверждение принимает только адресат.
- Отзывы «Полезный подбор» / «Не подходит». Счётчик взаимных согласий означает согласие, а не доказательство последующего разговора или сделки.
- Постоянная подписанная ссылка «Найти партнёра», которую владелец копирует в существующее приветствие или закреплённое сообщение. Старые кнопки приветствия не заменяются.
- Общая пауза CM, тарифная квота сообщений, часовой/дневной лимит, тихие часы для инициатив, проверка текущего членства и актуального username. Новые сообщения пишутся в общий журнал CM, AI-вызовы — туда же с моделью, токенами и длительностью.
- Дедупликация импорта, webhook и заданий, захват отправки, блокировка повторов при неопределённом результате Telegram. При `UNCERTAIN` оператор сначала проверяет чат.
- `/profile`, `/edit`, `/public`, `/private`, `/hide`, `/show`, `/forget`. Удаление очищает факты, источники и производные подборы, отменяет приглашения и оставляет минимальный запрет на восстановление повторным импортом. Оно доступно в прежнем личном контексте даже при паузе CM или выходе из сообщества.

## Как включить для Collaborations

1. Открыть нужное сообщество → CM → «Функции» → Collaber.
2. В «Настройках» указать сферу и цели; оставить инициативы в режиме черновиков. Загрузить свою обложку, изменить текст и кнопки.
3. «Участники» → «Загрузить историю», проверить примеры и запустить импорт. Исходный файл должен содержать стабильные Telegram ID, название человека само по себе недостаточно.
4. Проверить профили и исправить неточные интро. Публичные рекомендации первоначально запрещены: участник разрешает их через `/public`, либо владелец отмечает разрешение с согласия участника. Приватный подбор доступен для профилей, не скрытых из поиска.
5. Во вкладке «Предложения» проверить несколько задач без отправки. При необходимости обновить устаревшие интро: старый архив не подтверждает сегодняшнюю готовность.
6. Включить Collaber, сохранить и применить конфигурацию CM. Сам CM должен быть запущен.
7. Скопировать ссылку «Найти партнёра» в кнопку приветствия или закреплённое сообщение. Участник открывает бота, нажимает «Начать» и описывает задачу; в группе может обратиться к боту по имени/username или ответить ему.
8. Автоматические инициативы включать после проверки реального качества. До этого владелец просматривает и отправляет черновики вручную; тихие часы и общие лимиты действуют и для них.

## Архитектура и эксплуатация

Миграция `20260921120000_collaber` добавляет шесть таблиц: `CollaberProfile`, `CollaberImport`, `CollaberTask`, `CollaberRequest`, `CollaberSession`, `CollaberInvite`. Профиль связан с общим участником CM; все операции ограничены выбранным менеджером. Факты и их источники хранятся в JSON профиля. Внешняя векторная база не требуется.

`service.ts` извлекает и подбирает; `inference.ts` использует общий OpenAI-транспорт и журналирует usage; `telegram.ts` проверяет исполнителя, членство и согласие; `delivery.ts` формирует rich-сообщение и учитывает доставку; `worker.ts` обрабатывает очередь с ограниченными попытками; `routes.ts` предоставляет API владельца. В группе используется инструмент существующего агента, приватный диалог и фоновые инициативы обслуживает Collaber worker. Это отдельные процессы внутри того же CM, а не второй Telegram-бот.

Обложка и кнопки отправляются существующим `sendRichMessage`. При сетевой неопределённости автоматического запасного сообщения нет: оно могло бы продублировать успешную отправку. Владелец видит состояние и ошибку в «Предложениях» и общем журнале.

Импорт не публикует рекомендации сам по себе. Незавершённые предпросмотры/ошибки очищаются через семь дней; завершённые служебные задачи — через 30 дней. При `/forget` незавершённые импорты сообщества отменяются, поскольку они могут содержать удаляемые данные; загрузку можно повторить, запрет восстановления профиля сохранится. Удаление Collaber не отзывает уже отправленные Telegram-сообщения и не удаляет отдельную разговорную память CM; для удаления общего участника есть существующее действие CM.

## Что требует пилота или дальнейшей доработки

- Формат и объём файла проверены: 120 116 записей за 03.06.2024–22.09.2026, 107 651 пригодное текстовое сообщение после технической фильтрации. Подготовлены четыре части всей истории и альтернативная выборка 2 088 возможных интро. Это ещё не подтверждённые профили. Остаются замеры качества реального AI-извлечения и полезности выдачи. Пока поддержан JSON, не произвольные HTML/CSV-архивы.
- Полный четырёхшаговый мастер из первоначального плана заменён вкладками в существующей панели. Автоматического изменения приветствия нет: ссылка вставляется владельцем в существующий редактор.
- Источник открывается сохранённым текстом с датой; отдельная история всех версий профиля и прямые ссылки на каждую исходную реплику не реализованы.
- Результаты знакомства учитывают взаимное согласие. Отложенный опрос о том, состоялся ли разговор, оценка сделки и автоматическая подстройка ранжирования по отзывам пока не реализованы.
- Доставка rich-сообщения с обложкой и кнопкой входа подтверждена в тестовом чате. Остаются живые нажатия участников, подбор по их интро, контакт и взаимное согласие; внешний вид во всех клиентах Telegram не проверен. Проверка подбора без отправки не удостоверяет текущую доступность участника.

## Выпуск и откат

Следовать `deploy/README.md`: проверенный PostgreSQL dump и восстановление в отдельную БД, сохранение прежних API/web образов, fast-forward обновление, `docker compose up -d --build`, health, миграции, статика и журналы.

При проблеме сначала выключить Collaber или поставить CM на паузу. Прежние образы приложения можно вернуть, сохранив добавленные таблицы; восстановление рабочей БД из dump является отдельным решением, поскольку затрагивает записи после копии. Не сбрасывать `UNCERTAIN` без проверки фактической доставки.

### Подготовка выпуска 26.09.2026

- SSH по штатному ключу подтверждён. Для подключения при включённом Outline использован временный маршрут только к IP сервера; после работ он подлежит удалению.
- Резервная копия `/opt/publium-backups/collaber-20260926/before.dump` восстановлена в отдельную БД, подтверждены 59 прежних миграций. Сохранены образы `publium-api:before-collaber-20260926` и `publium-web:before-collaber-20260926`.
- Живой Telegram-пилот ограничен `Test Publium Chat`. Стандартный CM-бот читает все сообщения. История Collaborations не импортируется под ID тестового чата; качество архива проверяется отдельно, без отправок его участникам.

### Исправление проверки участников 27.09.2026

При живой проверке стандартный CM-бот (обычный участник) возвращал `left` для действующего владельца и неполный список администраторов. Подключённый бот Moderator с правами администратора подтвердил правильного владельца. Права в группе выданы корректно; переназначение владельца не требуется.

`membership.ts` выбирает CM, если он администратор, иначе проверяет права подключённого Moderator именно этого сообщества. Только этот исполнитель читает членство и текущие контакты; сообщения отправляет прежний CM. При отсутствии надёжного исполнителя проверка завершается ошибкой без ложной отметки о выходе участника. Исправление также применяется при публикации конфигурации CM и переключении на стандартного бота. Основание: [Telegram getChatMember](https://core.telegram.org/bots/api#getchatmember) гарантирует сведения о других участниках только ботам-администраторам.
